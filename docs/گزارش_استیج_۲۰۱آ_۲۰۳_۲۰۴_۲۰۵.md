## استیج 20.1A – آیکن اپ (لانچر آیکن)

### هدف
تنظیم آیکن لانچر اپ با لوگوی دایره‌ای صدی (پس‌زمینه سفید + لوگوی سبز پسته‌ای).

### کارهای انجام‌شده
- **منبع آیکن:** `assets/images/sedi_app_icon.png` (مربع، ترجیحاً ۱۰۲۴×۱۰۲۴) — در صورت نبود، کپی از `sedi_logo_1024.png` استفاده شد.
- **وابستگی:** به `dev_dependencies` اضافه شد: `flutter_launcher_icons: ^0.14.4`
- **تنظیم در pubspec.yaml:**
  ```yaml
  flutter_launcher_icons:
    android: true
    ios: true
    image_path: "assets/images/sedi_app_icon.png"
  ```
- **دستورات تولید:** بعد از `flutter pub get` اجرا شود:
  - `dart run flutter_launcher_icons`
- فایل‌های تولیدشده در `android/` و `ios/` برای آیکن لانچر به‌روز می‌شوند.

### تأیید
- `flutter analyze`
- `flutter test`
- `flutter build apk --debug`

## استیج 20.3 – Onboarding فقط با نام کاربری + حدس جنسیت

### هدف
حذف رمز/secret از onboarding؛ فقط نام کاربری (الزامی). حدس نرم جنسیت از نام برای شخصی‌سازی (غیرمسدودکننده). نام برند Sedi (EN) و صدی (FA/AR) در متن‌ها.

### کارهای انجام‌شده
- **صفحات onboarding و verification:** حذف فیلدها و اعتبارسنجی‌های مربوط به رمز؛ فقط فیلد «نام» (الزامی). ذخیره نام در UserProfile و preferences.
- **حدس جنسیت:** فایل جدید `lib/core/utils/gender_guess.dart`:
  - تابع `guessGender(String name, String langCode)` با خروجی `male` / `female` / `unknown`
  - FA/AR: پایان‌های ه، ة (زنانه نرم)
  - EN: پایان‌های a, e, ie (زنانه نرم)
- **ذخیره:** فیلد اختیاری `guessedGender` در UserProfile؛ در UI نمایش داده نمی‌شود.
- **API:** `ChatService.setupOnboarding(language, name: name)`؛ بک‌اند فقط `name` دریافت می‌کند.
- **متن UI:** placeholder چت و پیام خوشامد با نام برند Sedi/صدی یکسان شد.

### فایل‌های تغییر یافته
- `lib/core/utils/gender_guess.dart` (جدید)
- `lib/data/models/user_profile.dart` (فیلد guessedGender)
- `lib/features/chat/chat_service.dart` (setupOnboarding بدون password)
- `lib/features/onboarding/presentation/pages/onboarding_page.dart`
- `lib/features/user_verification/presentation/pages/user_verification_page.dart`
- `lib/features/chat/presentation/pages/chat_page.dart` (placeholder)

### تأیید
- `flutter analyze`
- `flutter test`
- دستی: onboarding فقط با وارد کردن نام و ارسال به چت برود.

## استیج 20.4 – رفع 422 چت؛ هم‌تراز کردن با بک‌اند

### هدف
هماهنگ کردن درخواست چت با الزامات بک‌اند برای حذف HTTP 422. لاگ دیباگ امن (بدون secret) و پیام خطای بهتر برای کاربر.

### کارهای انجام‌شده
- **قرارداد بک‌اند:** POST `/interact/chat` فقط بدنهٔ JSON با `user_id` (int) و `message` (string). بدون query param برای چت.
- **InteractRequest:** DTO با `userId` و `message` و متد `toJson()` مطابق بک‌اند.
- **جریان:** ChatController → ChatService.sendMessage → ChatRepository.sendChat(InteractRequest) → ارسال POST با JSON.
- **خطای 422:** ثبت endpoint، کلیدهای payload و جزئیات پاسخ؛ پر کردن `ChatLastErrorDump`؛ برگرداندن `REQUEST_FORMAT_ERROR`؛ نمایش در UI: «مشکل در فرمت درخواست. لطفاً دوباره تلاش کنید.» (و معادل EN/AR).
- **کمک دیباگ:** `lib/core/debug/chat_last_error_dump.dart` برای نگهداری آخرین خطا در حافظه (بدون ذخیره دائمی و بدون secret).

### فایل‌های تغییر یافته
- `lib/data/dto/interact_request.dart`، `interact_response.dart`
- `lib/data/repositories/chat_repository.dart` (sendChat)
- `lib/features/chat/chat_service.dart` (ساخت InteractRequest، ارسال JSON، مدیریت 422)
- `lib/features/chat/state/chat_controller.dart` (مدیریت REQUEST_FORMAT_ERROR)
- `lib/core/debug/chat_last_error_dump.dart` (جدید)

### تأیید
- `flutter analyze`
- `flutter test`
- دستی: ارسال یک پیام کوتاه → پاسخ 200 و پاسخ دستیار؛ در صورت 422، لاگ و ChatLastErrorDump قابل بررسی.

## استیج 20.5 – قفل نام برند: Sedi (EN) و صدی (FA/AR)

### هدف
یکسان‌سازی نام برند در همهٔ UI، اعلان‌ها، onboarding و intro: فقط Sedi در EN و صدی در FA/AR.

### کارهای انجام‌شده
- **Helper متمرکز:** `lib/core/utils/brand_name.dart`:
  - `sediBrandName(String langCode)` → برای `fa` و `ar` مقدار `'صدی'`، در غیر این صورت `'Sedi'`.
- **جایگزینی متن‌های هاردکد:**
  - پیام خوشامد (AppMessages)
  - placeholder باکس چت
  - متن fallback هدر (SediHeader)
  - متن mock تاریخچه چت
  - راهنماي دستگاه (مثلاً e.g. Sedi001)
  - نام و توضیح کانال اعلان‌های محلی
- **تست:** `test/brand_name_test.dart` برای fa/ar → صدی و en → Sedi.

### فایل‌های تغییر یافته
