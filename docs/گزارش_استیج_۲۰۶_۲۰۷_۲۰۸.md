## استیج 20.6 – اجرای نام برند (صدی در FA/AR؛ بدون سدی)

### هدف
یکسان‌سازی نام برند در همهٔ UI، intro، چت و اعلان‌ها: EN = "Sedi"، FA/AR = "صدی". املای اشتباه «سدی» در هیچ‌جا نباشد.

### کارهای انجام‌شده
- **جستجو:** در کل repo برای «سدی» جستجو شد؛ موردی یافت نشد. همهٔ رشته‌های قابل‌نمایش برای کاربر از `sediBrandName(langCode)` (استیج 20.5) استفاده می‌کنند.
- **brand_name.dart:** توضیح اضافه شد که از «سدی» استفاده نشود و برای FA/AR فقط از همین helper استفاده شود. خروجی برای fa/ar: «صدی».
- **تست:** در `test/brand_name_test.dart` تأیید شده که برای fa و ar مقدار «صدی» برگردانده می‌شود و مقدار «سدی» برگردانده نمی‌شود (`isNot('سدی')`).
- **پوشش:** پیام خوشامد، placeholder چت، fallback هدر، mock تاریخچه چت، راهنمای دستگاه، کانال اعلان‌ها همگی از helper استفاده می‌کنند.

### فایل‌های تغییر یافته
- `lib/core/utils/brand_name.dart` — کامنت و یادداشت (صحیح: صدی).
- `test/brand_name_test.dart` — تست‌های fa/ar → صدی و عدم استفاده از سدی.

### تأیید
- `flutter analyze`
- `flutter test test/brand_name_test.dart`
- **دستی:** اجرای اپ با locale FA یا AR؛ اطمینان از نمایش «صدی» و عدم نمایش «سدی».

## استیج 20.7 – متن تأییدشدهٔ سلام intro + یک‌بار برای هر کاربر

### هدف
جایگزینی greeting با متن تأییدشدهٔ محصول برای intro. در FA/AR فقط «صدی»، در EN فقط «Sedi». نمایش سلام فقط یک‌بار به‌ازای هر کاربر (پرچم پایدار)؛ بدون درج مجدد بعد از باز کردن دوبارهٔ اپ.

### کارهای انجام‌شده
- **greeting_templates.dart:** فایل جدید با متن تأییدشدهٔ FA/EN/AR. تابع `getIntroGreeting(langCode)` متن دقیق را برمی‌گرداند:
  - **FA:** «من صدی هستم؛ دستیار هوشمند مراقبت سلامت شما…» (شامل گجت، مراقبت پیوسته، صدی).
  - **EN:** "I'm Sedi, your intelligent health-care companion…" (شامل Sedi, specialized gadgets, continuous).
  - **AR:** «أنا صدی، مساعدك الذكي…» (شامل صدی).
- **ChatController:** به‌جای greeting از backend، از قالب‌های intro استفاده می‌کند. متد `_showIntroGreetingOnce()`:
  - اگر `UserPreferences.hasSeenIntroGreeting()` برابر true باشد → هیچ سلامی اضافه نمی‌شود (بدون تکرار بعد از بازگشایی).
  - در غیر این صورت → نمایش `getIntroGreeting(lang)` و سپس `setHasSeenIntroGreeting(true)`. زبان از پروفایل یا UserPreferences.
- **UserPreferences:** اضافه شدن `hasSeenIntroGreeting()` و `setHasSeenIntroGreeting(bool)` برای ذخیرهٔ دیده شدن سلام.
- **تست:** `test/greeting_templates_test.dart` — FA/AR شامل «صدی» و بدون «سدی»؛ EN شامل "Sedi"؛ FA شامل «گجت» و «مراقبت پیوسته»؛ EN شامل "specialized gadgets" و "continuous".

### فایل‌های تغییر یافته
- `lib/features/chat/logic/greeting_templates.dart` (جدید)
- `lib/core/utils/user_preferences.dart` — پرچم hasSeenIntroGreeting
- `lib/features/chat/state/chat_controller.dart` — استفاده از _showIntroGreetingOnce و قالب‌ها
- `test/greeting_templates_test.dart` (جدید)

### تأیید
- `flutter analyze`
- `flutter test test/greeting_templates_test.dart`
- **دستی:** نصب تازه → سلام یک‌بار نمایش داده شود؛ باز کردن دوبارهٔ اپ → بدون سلام تکراری. در FA/AR متن intro باید «صدی» را نشان دهد.

## استیج 20.8 – اصلاح آیکن اپ (لوگوی دایره‌ای صدی)

### هدف
آیکن لانچر دقیقاً: **پس‌زمینه دایره سفید + لوگوی سبز پسته‌ای صدی در مرکز**. استفاده از flutter_launcher_icons؛ کامیت کردن خروجی‌های تولیدشده؛ افزایش نسخه/versionCode تا دستگاه بعد از نصب/به‌روزرسانی آیکن جدید را نشان دهد.

### کارهای انجام‌شده
- **منبع آیکن:** `assets/images/sedi_app_icon.png` (مربع ۱۰۲۴×۱۰۲۴ پیشنهادی؛ ظاهری: دایره سفید + لوگوی سبز پسته‌ای در مرکز). در صورت عدم تطابق طراحی، این فایل را جایگزین کنید.
- **pubspec.yaml:** تنظیم flutter_launcher_icons از قبل روی `assets/images/sedi_app_icon.png` با android و ios فعال است.
- **افزایش نسخه:** `1.0.0+1` → `1.0.0+2` تا versionCode اندروید افزایش یابد و بعد از نصب/به‌روزرسانی آیکن به‌روز دیده شود.
- **مستند:** `docs/APP_ICON.md` — توضیح منبع آیکن، تنظیمات، دستورات `flutter pub get` و `dart run flutter_launcher_icons`، کامیت خروجی‌های تولیدشده و تأیید.

### فایل‌های تغییر یافته
- `pubspec.yaml` — version به 1.0.0+2
- `docs/APP_ICON.md` (جدید)
- بعد از اجرای `dart run flutter_launcher_icons` باید خروجی‌های زیر کامیت شوند:
  - `android/app/src/main/res/mipmap-*/ic_launcher.png`
  - `ios/Runner/Assets.xcassets/AppIcon.appiconset/*.png` (و در صورت تغییر، Contents.json)

### تأیید
- `flutter analyze`
- `flutter test`
- `flutter build apk --debug`
- **دستی:** حذف نسخه قبلی اپ، نصب بیلد تازه؛ بررسی آیکن لانچر (دایره سفید + لوگوی سبز پسته‌ای).
